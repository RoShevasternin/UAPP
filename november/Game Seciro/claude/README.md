# Seciro — усе для роботи Claude

Апка безпеки «все в одному» за підпискою: VPN, Web Protection, QR-сканер, Storage Cleaner,
Breach Check, генератор паролів. Kotlin + LibGDX. Початок — 24.11.2026 (VELDAN).

## Головне правило: спершу прототип

**З 26.11 (VELDAN):** робимо строго за Figma і документацією, навіть iOS-місця (Safari, Face ID, iPhone) — як є, нічого від себе.
Що на Android не працюватиме — лише позначаємо у вкладці кіта (скрін + червона рамка + що виправити), самі не правимо.
Відкриті питання — пам'ять `seciro-open-questions`. Задачі Віталія — у ClickUp (доступ дадуть пізніше).

1. Екран спершу робимо в **прототипі** (`../prototype/`) і публікуємо на claude.ai.
2. VELDAN проклацує й править. Поки прототип не прийнято, у Kotlin екран не переносимо.
3. Перенос у `../Seciro/` (Kotlin + LibGDX) → перевірка на **десктопі** (`sh ./gradlew :desktop:run`,
   вікно 375×812) → лише потім **реальний Android по USB**.

### Рендерер кадрів Figma (з ряду 3) — `prototype/fig.jsx`

Екран малюється прямо з дерева шарів: збирач v2 у вкладці Figma (див. `figma/README.md`) кладе
`figma/r<N>/<кадр>.json` (ax/ay від кадру, заливки, рамки, тіні, тексти з runs) і PNG @3x усього векторного
(дедуплікація за хешем). `build.py` → `.tools/fig.gen.js`. Поведінку додає екран через overrides
(`{[id|ім'я]: false | {onClick, className, style} | (node, el, pos) => el}`). Leading trim Figma → `text-box: trim-both cap alphabetic`.
Ряди 1–2 зроблено вручну (лишаються як є); з ряду 3 — лише рендерер + поведінка.
Пастки (ряд 4): шари, обрізані кадром (низ скрол-списків), не експортуються → брати PNG головного компонента
(`r4/missing.json`, `r4/flags.json`); екземпляр компонента ≠ компонент за полями (прапори) → видимі брати з екземпляра,
обрізані — з дитини компонента; м'які градієнти PNG важать мегабайти → JPEG на тлі кадру (`build.py` / ручний крок);
кадри Figma в колонці порівняння — JPEG-копії (`.tools/frames`), межа артефакту 16 МБ. У тестах headless вимикати
CSS-переходи й анімації (інакше елементи «застигають» посеред руху).

## Чи все це реалізовне на Android (оцінка 24.11)

- UI, анімації, переходи, пейджер, аркуші — так, LibGDX (Scene2D + шейдери, як Orbit Dash).
- VPN — так: WireGuard у `VpnService`; системний дозвіл Android перед першим підключенням обов'язковий.
- Web Protection — НЕ як у макеті (розширення Safari на Android немає). Реально: фільтр DNS / доменів усередині нашого ж
  `VpnService` (Android дозволяє лише один VPN одночасно → блокування й VPN — один сервіс).
- QR-сканер — так: CameraX + ML Kit (штрихкоди) + перевірка посилання (Google Safe Browsing / Web Risk API, сервер).
  Камера — нативний шар Android поверх LibGDX.
- Storage Cleaner — так: MediaStore (READ_MEDIA_IMAGES / VIDEO), видалення через системне підтвердження `createDeleteRequest`.
- Breach Check — так, через API витоків (напр. Have I Been Pwned — платний ключ) і краще через наш сервер.
- Password Generator — так, локально (SecureRandom).
- Перевірки «Protection review» — ті самі 4 пункти, що в дизайні, з Android-змістом (питання до Віталія, 27.11): Web Protection = VPN
  увімкнено, Software Update = рівень патча (`Build.VERSION.SECURITY_PATCH`), Passcode = блокування екрана (`KeyguardManager.isDeviceSecure`),
  Face ID = відбиток / обличчя (`BiometricManager`). Своїх пунктів (Play Protect, режим розробника) не додаємо — нічого від себе.
- Вхід за поштою з кодом і перевірка підписки — потрібен бекенд (серверна команда); оплата — Google Play Billing.

## Документація для Android (оновлення 26.11)

Розділ «Seciro for Android» у тих самих Docs (`/admin/docs?lang=uk#android-overview`; текст не комітимо). Головне:

- Пакет **`app.seciro.android`** (Google Play: «Seciro: Phone Security & VPN») — замінити тимчасовий `com.seciro.app`.
  `X-App: seciro_android` працює і обов'язковий у кожному запиті (без нього сервер апку не впізнає).
- `X-Install-Id`, сесія й renewal-токен — поза бекапом Android (`noBackupFilesDir` / `dataExtractionRules`), шифровані ключем з Keystore.
- Працює зараз: вхід кодом, renew, logout, знімок пристрою, події, перевірка доступу, Breach Check, кабінет (Custom Tabs),
  видалення профілю, `requiredVersion`. Тестовий акаунт від Віталія (Slack 26.11) — відкриває Android-апку як `test`.
- **Віталій:** доступ визначаємо лише за `entitled`, `state`, `denial`; поля `premium`, `product`, `oneOffs`, `plans[].store`
  ще в розробці — не чіпати; задачу «Куплені разові покупки в акаунті» не починати.
- В розробці: покупки Google Play (окремий акаунт RevenueCat; підписка `app.seciro.android.premium`, базові плани
  `weekly`/`monthly`/`yearly`, пробна `weekly-trial` — id остаточні), ліміт пристроїв (поки Android місця не займає),
  вхід після покупки на сайті (Play Install Referrer), видалення акаунта на сайті, **VPN** (протокол вирішують, найімовірніше
  IKEv2 → мін. Android 11; поки `403 no_access`).
- **Web Protection на Android = захист від шахрайських сайтів усередині VPN і лише коли VPN увімкнений** (не Chrome/Private DNS).
  Подія `safari_ext` не шлеться; значення `shield_toggle.filter` погоджуються разом з екранами модуля.
- Без відповіді поки: джерело вердикту QR, підтримка/Alerts/пуші.

## Ряд 5 — Web Protection (build 18, 26.11)

8 кадрів (5:3919 перший вхід · 5:6791 знайомство · 5:7412 5/5 · 5:7024…5:6927 4/5…0/5). Рівень = скільки з 5 фільтрів увімкнено;
базовий кадр за рівнем, рядок фільтра — з кадру «все ввімк.» (5:7412) або «все вимк.» (5:6927), перетікання. Головний перемикач:

## Storage Cleaner на Android: як шукаємо дублікати (план, 27.11)

Усе на телефоні, без сервера (у документації лише події `cleanup_scanned` / `cleanup_done`). Нативний шар Kotlin, екрани LibGDX отримують групи й прогрес.
- Доступ: MediaStore; `READ_MEDIA_IMAGES` / `READ_MEDIA_VIDEO` (13+), `READ_EXTERNAL_STORAGE` (10–12); Android 14 — частковий доступ (плашка «Дозволити всі»).
- Screenshots — фото з теки `Screenshots` (RELATIVE_PATH / bucket).
- Duplicate Photos — групи за розміром файла → хеш вмісту лише для збігів (100 % копії).
- Similar Photos — перцептивний хеш (pHash/dHash) з мініатюри (`loadThumbnail`), відстань Геммінга ≤ поріг; порівнюємо лише знімки,
  близькі в часі (серії). «Найкраще» в групі — різкість (дисперсія Лапласіана), роздільність, новіше. Якщо мало — TFLite-ембединги.
- Similar Videos — 3–4 кадри (`MediaMetadataRetriever.getFrameAtTime`) + хеші + тривалість.
- Фон із прогресом (кільце «Scanning…»), кеш хешів у локальній БД за id + date_modified — повторний скан за секунди.
- Видалення — `MediaStore.createDeleteRequest` (11+, системне вікно); Android 10 — по файлу (RecoverableSecurityException).
- Пороги підбирати на девайсі на тестовій галереї (серії, скріни, копії з месенджерів).
