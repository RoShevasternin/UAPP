    Що з цього взято в прототип

    • Головний екран — за згодою людини: пояснення, «Maybe later», перемикач у Settings. Без «SCAM ALERT».
    • Живий відеофон з власних відео: у завантажувачах шпалери є лише в 3% апок, а лаунчера з відеофоном немає ні в кого.
    • Картка лінка на головному лише для того, що можна зберегти. YouTube тощо тихо ігнорує.
    • HLS без захисту — рідкісна функція (7%). Стріми з DRM чи AES отримують чесну відмову.
    • Studio: обрізка, звук M4A, GIF або MP4-петля, частини для Status (60 с, ◌ WhatsApp уже дозволяє 90 с), кадр, стиснення.
    • Discover — лише суспільне надбання і CC, з бейджем ліцензії й титрами у файлі.

    Тонкощі

    ✔Android-екран із роллю HOME не може піти в PiP (перевірка в AOSP ActivityRecord). Потрібна окрема PlayerActivity.
    ✔У Android немає енкодерів MP3 і GIF. M4A є всюди. Для MP3 потрібен LAME (LGPL), для GIF — свій енкодер або MP4-петля.
    ✔Media3 Transformer офіційно не приймає HLS. Сегменти качаємо самі, склеюємо і тоді перепаковуємо в MP4.
    ✔Саундтрек Tears of Steel — CC BY-ND, тож змінену версію не можна поширювати.
    ◌Ліцензію на Internet Archive вказує той, хто завантажив. Тому тримаємо вибраний список і пропускаємо елементи з is_dark.
    ◌17 апок з ≥100 тис. встановлень ховають оцінку й дату. Цифри гібридів можуть бути накручені.

    Як ляже на LibGDX

    • Каркас з Redwave майже без змін: MainActivity з HOME + LAUNCHER + SEND, ClipGate, PlatformBridge, DownloadManager → Movies/Framefall, Remote Config.
    • Лаунчер із Driftglass: одна сторінка, автопапки, свайп угору — усі апки.
    • Відео в GL: ExoPlayer → SurfaceTexture → текстура GL_TEXTURE_EXTERNAL_OES у шейдері. Так скляні картки з розмиттям лягають прямо на відеофон. Запасний варіант: SurfaceView під прозорим GL. ◌ Перевірити на Redmi.
    • Плеєр і PiP: окрема PlayerActivity (не HOME, своя taskAffinity, singleTask) з Media3 PlayerView.
    • Studio: Media3 Transformer 1.11.1 — ClippingConfiguration, setRemoveVideo → M4A, Presentation для стиснення, частини для Status. Кадр — FrameExtractor.
    • HLS: свій завантажувач сегментів (OkHttp) → склейка → Transformer → MP4. Відмова, якщо EXT-X-KEY ≠ NONE або в DASH є ContentProtection.
    • port-kit: LinkResolver → VideoLinkResolver (Archive, NASA, Commons, PeerTube, m3u8, ширший блок-лист), AudioSniffer → VideoSniffer (ftyp, EBML, OggS, TS 0x47).

    Відкриті рішення для VELDAN

    • Назва й пакет: «Framefall: Video Downloader» (27/30) чи «Framefall: Video Home Launcher» (30/30), як у Redwave. Пакет — пропоную com.framefall.video.
    • Реклама: як у Redwave (AdMob в апці)? Рекламу на кнопку «Додому» Google забороняє прямо (Disruptive Ads ✔).

    • MP3: додати LAME (LGPL, +~1 МБ) чи лишити M4A. GIF: свій енкодер чи лише MP4-петля.
    • v1 чи v1.1: HLS, PeerTube, відео як системні живі шпалери (WallpaperService, діє й поза нашим лаунчером).
    • Discover: вибраний список (≈30 фільмів Archive + NASA + Blender) у catalog.json на GitHub raw, як у Redwave.
