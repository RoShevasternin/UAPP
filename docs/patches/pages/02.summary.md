## Що і навіщо

Щоб перевірити Meta на телефоні **до того**, як сервер почне віддавати блок `meta`, debug-збірка RBX Boss бере тестові ключі з `local.properties`. Цей файл у git не йде.

- Ключі з сервера завжди мають перевагу. Тестові вмикаються, лише коли блоку `meta` немає.
- Release тестових ключів не бачить ніколи: у ньому ці поля порожні, перевірено.
- Інших змін у поведінці немає: без ключів апка працює як зараз.

## Крок 1. Акаунт розробника Meta

- Відкрий **developers.facebook.com** і увійди Facebook-акаунтом, з якого керуватимеш рекламою.
- Якщо заходиш уперше: **Get Started** → підтвердь пошту чи телефон → роль Developer.

## Крок 2. Створити Meta App для RBX Boss

- **My Apps → Create App**.
- Сценарій (use case): **Other**, тип застосунку: **Business**. Назви кнопок у Meta часто змінюються, тож обирай варіант без Facebook Login.
- Назва: `RBX Boss`, контактна пошта. Business portfolio — твій бізнес-акаунт, з якого підуть кампанії. Можна додати й пізніше.

## Крок 3. Забрати два ключі

| ключ | де | куди |
|---|---|---|
| **App ID** | App Dashboard → **Settings → Basic** (його видно й угорі кабінету) | `meta.testAppId` |
| **Client Token** | App Dashboard → **Settings → Advanced → Security → Client token** | `meta.testClientToken` |

**App Secret** не бери й нікому не передавай: в апку і в конфіг він не йде.

## Крок 4. Налаштування в кабінеті Meta

- **Settings → Basic**: Privacy Policy URL (той самий, що в Google Play), іконка, категорія → **Save changes**.
- Там же внизу **Add platform → Android**:
  - Google Play Package Name: `com.bossrbx.rbxcalculator`
  - Class Name: `com.bossrbx.rbxcalculator.StartActivity`
  - Key Hashes лишити порожніми: вони лише для Facebook Login.
  - Перемикач **Log in-app events automatically** — увімкнений.
- **Save changes**.

## Крок 5. Вставити ключі локально

Відкрий `april_may/Game T5/RBX Boss/local.properties` і допиши в кінець два рядки:

```
meta.testAppId=ТВІЙ_APP_ID
meta.testClientToken=ТВІЙ_CLIENT_TOKEN
```

Збери **debug** і постав на телефон. Можу зробити це сам — просто скажи.

## Крок 6. Перевірити, що працює

- **Logcat** (фільтр `BOSSER` або `FacebookSDK`): мають бути `Meta: тестові ключі з local.properties` і `Meta SDK initialized SUCCESSFULLY`, а далі `FacebookSDK.AppEvents … Flush completed` без помилки 190.
- **Meta:** Events Manager → твій застосунок → **Test events**, або developers.facebook.com/tools/app-ads-helper → застосунок → **Test App Events**. Протягом кількох хвилин мають з'явитися запуск застосунку й `Achievement Unlocked` (відкриття головного екрана).
- Помилка `190 / OAuthException` у лозі означає неправильний App ID або Client Token: перевір, що скопійовано без пробілів.

## Крок 7. Коли все працює

- Передай **App ID і Client Token** серверній команді в картку RBX Boss, блок `"meta": {"app_id": "…", "client_token": "…"}` поруч із `tiktok`. Після цього тестові рядки з `local.properties` можна прибрати.
- Business Manager → **Business Settings → Accounts → Apps**: застосунок у твоєму бізнес-портфоліо, доступ дано рекламному акаунту.
- Перед запуском реклами: **App Mode → Live** у верхній панелі кабінету і **Play Console → Data safety** з даними, які збирає Meta SDK (рекламний ID, взаємодія з апкою).

## Перевірено

- Debug і release збираються.
- Вигадані ключі в `local.properties` потрапляють у `BuildConfig` debug-збірки, а в release там порожньо.
