## Що і навіщо

Підключаємо **Meta (Facebook) SDK** поруч із TikTok. Беремо лише модуль подій `facebook-core` 18.3.0, без Login і Share. Він шле в Meta встановлення, запуски й одну нашу подію. На цих даних реклама Meta Ads рахує встановлення й оптимізує кампанії.

Зроблено дзеркально до TikTok:

- **Ключі приходять із нашого конфіг-сервера**, блок `meta` поруч із `tiktok`. Блоку немає — SDK не стартує, і апка працює як раніше.
- `MetaManager` — запуск SDK із цими ключами.
- `MetaAnalyticsProvider` — подія `fb_mobile_achievement_unlocked` на відкриття головного екрана. Це те саме місце, де TikTok шле `UNLOCK_ACHIEVEMENT`.
- Запуск підстрахований з двох боків. Перший — із кешованого конфігу в `App.onCreate`, ще до першого екрана, щоб Meta бачила початок сесії. Другий — після свіжого конфігу в `MainActivity`, на випадок найпершого запуску. Повторний виклик ігнорується.

Зміни однакові для **RBX Boss (T5)**, на якій ти зараз працюєш, і для **еталона** T1-integrated. Еталон оновлюємо, щоб наступні міграції одразу йшли з Meta. Решту мігрованих апок переведемо окремими патчами після перевірки з живими ключами.

## Де взяти ключі Meta (окремо для кожної гри)

Апці потрібні лише **App ID** і **Client Token**. **App Secret** не кладемо ні в апку, ні в конфіг: Meta прямо забороняє зашивати його в застосунок.

| що | де взяти |
|---|---|
| Meta App | developers.facebook.com → My Apps → Create app. Раджу окрему Meta App на кожну гру: у кожної свій пакет і свої кампанії |
| **App ID** | App Dashboard → Settings → Basic (також видно вгорі кабінету) |
| **Client Token** | App Dashboard → Settings → Advanced → Security → Client token |
| Платформа Android | Settings → Basic → Add platform → Android. Package name: `com.bossrbx.rbxcalculator` (T5), `com.rbxhubpro.rohumex` (еталон). Class name — стартова активіті: `com.bossrbx.rbxcalculator.StartActivity` / `com.rbxhubpro.rohumex.StartActivity` |
| Key hashes | Не потрібні: вони лише для Facebook Login, а ми його не підключаємо |
| Реклама | Застосунок додати в Business Manager (Business Settings → Accounts → Apps) і дати доступ рекламному акаунту, з якого підуть кампанії. Назви пунктів у кабінеті Meta часто змінюються — орієнтуйся за змістом |

Перевірити в кабінеті перед запуском реклами: чи застосунок у режимі **Live** (App Mode) і чи заповнено **Privacy Policy URL** у Settings → Basic.

## Що має віддавати сервер

Блок у картці кожної апки, поруч із `tiktok`. Значення в кожної гри свої:

```
"meta": {
  "app_id": "123456789012345",
  "client_token": "0123456789abcdef0123456789abcdef"
}
```

Блоку немає або одне з полів порожнє — апка пише в лог `Meta config missing/invalid — skip init` і працює без Meta.

## Перевірено

- **Збірка в лабораторії:** обидві гри, debug і release (з R8). Помилок немає.
- **Реальний девайс, RBX Boss без блоку `meta`:** `Meta config missing/invalid — skip init`, TikTok стартує, крашу немає, гра відкриває лендінг як завжди.
- **Емулятор, еталон із вигаданими ключами:** `Meta SDK initialized SUCCESSFULLY`, подія `fb_mobile_achievement_unlocked` пішла в Meta. Сервер Meta відхилив вигаданий ключ — так і має бути.
- Рядок `FacebookInitProvider: Failed to auto initialize` на старті очікуваний і нешкідливий. Meta намагається стартувати сама, але ключів у маніфесті немає. Справжній запуск іде з `MetaManager`.

## Коли будуть справжні ключі

- **Events Manager** → застосунок → **Test events**, або **App Ads Helper** → Test App Events. Мають з'явитися встановлення, запуск і `Achievement Unlocked`.
- У debug-збірці події видно в logcat за тегом `FacebookSDK.AppEvents`.
- **Play Console → Data safety:** Meta SDK збирає рекламний ID і дані про взаємодію з апкою. Анкету треба оновити до релізу.

## Обмеження

Найперший запуск після встановлення: SDK стартує вже після відкриття екрана, тож початок цієї сесії Meta не бачить. Подія встановлення при цьому йде, і атрибуцію це не ламає. З другого запуску SDK стартує з кешу ще до першого екрана.
