Кожен новий екран прототипу Seciro робимо **одразу живим**: анімації появи, справжні перемикачі/чекбокси/кнопки з
відгуком, переходи, прогрес-бари, наповнення — **преміально, але в міру** (це утиліта безпеки, не гра: без «стрибків» і конфеті).
Приклад ряду 5: перемикач кодом (кулька їде), головний перемикач — каскад, картка рівня перетікає, блоки з'являються знизу.

Нотатки до екранів (`prototype/notes.js`): до питань і правок додаємо **приклад-начерк** «як має виглядати» (`ex`), він показується
зліва замість кадру Figma (кнопка «Приклад →»), щоб і менеджер, і дизайнер одразу бачили, що від них хочуть. Начерки —
`claude/tools/sketches/wf.py` (+ `flows.py`), генерація `gen_examples.py` → `prototype/examples/*.svg`.

Панель прототипу — без зайвого (VELDAN 26.11 прибрав «Compare»/накладання/довгі пояснення): список екранів зі статусом і NEW,
«Лише нові», нотатки.

Тексти нотаток — **прості**: одне питання/дія одним реченням, «Питання менеджеру: …?» / «Дизайнеру: …», без технічних
термінів (VELDAN 26.11: «питання складнуваті»). Анімації без перемонтування й без перетікання напівпрозорих карток
(мерехтить) — міняти колір/стан, а не цілі шари.

**Why:** VELDAN 26.11.2026 — апка за підпискою має виглядати якісно; кіт/прототип мають бути зрозумілі менеджеру й дизайнеру без пояснень.
**How to apply:** кожен ряд: зібрати з Figma → оживити → нотатки + приклади + NEW → звірка (proto-diff) + автотест → публікація.
