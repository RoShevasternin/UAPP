Після кожної оновленої апки користувач просить «реліз нотс» — це текст для Google
Play «What's new», **англійською**, 2–3 короткі абстрактні пункти: оновили
бібліотеки, оптимізували пам'ять/продуктивність, стабільність і баг-фікси.

**Why:** 23.09.2026 спершу дав технічні нотатки, потім детальний перелік фіч —
обидва рази користувач поправив: «не треба все розписувати… так абстрактно».

**How to apply:** одразу давати блок на 3 рядки; формулювання трохи варіювати між
апками, щоб не були дослівно однакові. Технічні нотатки — лише якщо попросить явно.
