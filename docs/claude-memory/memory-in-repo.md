30.09.2026 пам'ять перенесли в репо: `/Users/admin/Apps/UAPP/docs/claude-memory/`. Старе місце `~/.claude/projects/-Users-admin-Apps-UAPP/memory` тепер симлінк на цю теку.

**Why:** Користувач працює з двох акаунтів Claude: коли в одному закінчується ліміт, переходить на інший. Хоче, щоб пам'ять була в проєкті, на Маці й на GitHub. Сказав так: «щоб все пам'яталось». На цьому Маці обидва акаунти мають спільну `~/.claude`, тож симлінк покриває обидва.

**How to apply:**
- Записав або змінив пам'ять — закомітити й запушити `docs/claude-memory` разом з іншою роботою. Окремо не питати, бо це прохання користувача.
- **Пуш із терміналу Claude не працює** (01.10.2026): у git немає логіна до GitHub (`could not read Username`), `gh` не авторизований. Комітимо самі, а пушить VELDAN через GitHub Desktop — сказати йому про це в кінці відповіді. Налаштування доступу самостійно не міняти.
- Репо публічне ([[uapp-git-backup-public-repo]]). Тому в пам'ять не пишемо особистих оцінок користувача чи колег, лише факти й рішення.
- Якщо симлінк зник (новий Мак, переустановка), відновити за командою з `CLAUDE.md`, розділ «Пам'ять Claude».
- Опис теки `docs/research/` теж є в `CLAUDE.md`. Див. [[artifact-then-save-on-request]].
