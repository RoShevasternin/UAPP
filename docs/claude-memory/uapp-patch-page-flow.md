01.10.2026 VELDAN попросив перенести в UAPP систему з Orbit Dash: Claude дає результат на claude.ai — які класи створити, змінити чи видалити. Користувач по кожній зміні обирає «вставлю сам» або «автоматично», а Claude читає вибір і робить решту. Сказав запам'ятати, щоб так працювали всі сесії з обох акаунтів.

**Why:** VELDAN сам вирішує, що вставляє руками, а що віддає Claude. Сторінка тримає історію патчів поза scratchpad. Працює з телефона.

**How to apply:**
- Повна процедура, команди й таблиця посилань — `docs/patches/README.md`. Коротко — `CLAUDE.md`, розділ «Сторінки-патчі».
- Файли ігор не правити без вибору на сторінці чи прямого прохання. Зміни робити в лабораторії (scratchpad, шляхи від кореня UAPP), там збирати debug + release і перевіряти на девайсі. Потім `build.py` → публікація з `capabilities: {artifact: {}}` → запис `docs/patches/NN-*.md` → посилання в README.
- Рядок у чаті `Патч NN · Готово · сам X · авто Y` означає одразу: `Artifact read` сторінки → `state` → «авто» вставити дослівно (`old` рівно 1 раз у файлі), «сам» перевірити → збірка, девайс, скріншот → `mark.py` → публікація на той самий URL → коміт і пуш.
- Сторінку збирати до вставки (див. пастки в README).
- Шаблон доопрацьовано під UAPP: групування за грою (`projects` у спеці), блоки ```, документ для самопублікації — у формі інструмента Artifact.
