Усі питання «як це буде на Android» вирішуємо ми з VELDAN як розробники. Дизайнер вирішує лише, як це виглядає.
Віталію (менеджер) — лише продуктові рішення, і завжди просто: по одному питанню в картці, варіанти A/B/C з живими прикладами (дати, шляхи в налаштуваннях).

**Why:** 28.11.2026 VELDAN не зрозумів нотатки «підпис інший», «Face ID лише на iPhone» і питання Віталію без прикладів: «прям ясно розписати дизайнеру, які мають бути кроки англійською… всі питання по андроід маємо вирішувати ми з тобою».

**How to apply:** у нотатці дизайнеру — дослівний англійський текст на заміну, по рядку на кожен елемент екрана, плюс «весь текст екрана (EN)» для копіювання. Наші рішення позначати kind `android` з поясненням, чому так (пошук у Налаштуваннях, кнопка Open Settings). Нотатку «як буде на Android» ділити на ✔ точно / ◌ не вирішено. Приклад — `sheet-update` і Protection Review у `prototype/notes.js` (build 23).
