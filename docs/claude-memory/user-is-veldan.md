Користувач — це VELDAN. У звітах, брифах, аналізах та інтерактивних презентаціях (артефактах), які він дає колегам, авторство позначаємо як «Підготував VELDAN» — **зверху, на видному місці** (у шапці поруч з назвою), а не лише у футері; у багатомовних сторінках локалізувати («Подготовил VELDAN» / «Prepared by VELDAN»). Користувач окремо просив про це 30.09.2026 — не забувати в кожному новому артефакті. У документах Claude Docs це окремий рядок під вступом, бо рядок авторства там має бути лише дата · автор.
