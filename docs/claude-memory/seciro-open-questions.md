Seciro для Android: список невирішеного на **26.11.2026**. Коли питають «чого нам ще треба» — відповідати за ним
(і звірити з оновленою документацією в адмінці — розділ «Seciro for Android» міг змінитись). Пов'язане: [[vpn-app-new-type]], [[seciro-build-by-design]].

**Вирішують вони (в документації «in development»):**
1. VPN — протокол (найімовірніше IKEv2) і дані підключення; від нього мін. Android (10 або 11). Зараз Android отримує `403 no_access`. Віталій сказав, що займається VPN сам.
2. Web Protection = захист усередині VPN, лише коли VPN увімкнений: хто фільтрує (сервер VPN чи апка), звідки списки, які фільтри (значення `shield_toggle.filter` «погоджуються разом з екранами модуля»).
3. Покупки Google Play: сервер ще не приймає; окремий акаунт/проєкт RevenueCat і SDK-ключ — від них; доступ до Play Console дадуть нам. Id підписки вже остаточні (`app.seciro.android.premium`, `weekly`/`monthly`/`yearly`, `weekly-trial`).
4. Ліміт пристроїв iPhone + Android — правило перевіряють; поки Android місця не займає.
5. Вхід після покупки на сайті (Play Install Referrer) — запит ще не описаний.
6. Сторінка видалення акаунта на сайті — адреса потрібна для анкети Google Play.

**Ніхто не відповів:**
7. QR — звідки вердикт safe/warning/unsafe (сервер, сервіс чи правила в апці).
8. Need help / Get help і Contact — що відкривається (чат, пошта, сторінка).
9. Вкладка Alerts — що показувати і звідки дані.
10. Пуші — чи шле сервер, хто налаштовує Firebase/FCM для Android.
11. Екрани, яких немає у Figma (замкнені модулі, результати QR, «оплата не пройшла», «пристрій вийшов», «немає інтернету»…) — Віталій сказав, що займеться; коли — невідомо.
12. Тестовий акаунт (Slack Віталія 26.11) — чи ті 6 цифр постійний код (припущення; у репо код не писати).
13. Скріни планшета для Google Play — вертикальні чи 1920×1080 (питання до Віталія перед релізом).

**Не питання:** задачі Віталія — у ClickUp, доступ VELDAN дасть, коли буде треба. Мови апки, перевірки Protection Review для Android
тощо — не вигадуємо: робимо як у дизайні ([[seciro-build-by-design]]).
