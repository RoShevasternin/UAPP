Нові продукти під одну модель: користувач дивиться рекламу й отримує щось безкоштовно. Станом на 30.09.2026 вертикалей три:

1. **RBX-монетки** — наші нинішні ігри парку (див. [[uapp-employer-and-repo]]).
2. **Безкоштовні стрімінги** (YouTube Premium, Netflix, Spotify…) — веде **Тарас**. Бриф: https://claude.ai/artifact/9Fh7k46NUXF4BcRC7Y3jdk, копія `docs/research/briefs/TARAS-reward-ads-29-09-2026/`.
3. **TikTok-користувачі** (накрутка, TikTok-монетки, AI-інструменти для відео тощо) — веде **Nasuf**. Бриф 30.09.2026 — інтерактивний артефакт 4 мовами з прапорцями: https://claude.ai/artifact/RaT2KKrtWHNHdY1j1mLSSu (посилання з `#uk` / `#ru` / `#en` / `#tr` відкривають потрібну мову; для Nasuf — `#tr`). Усередині 7 напрямів із готовими запитами в Play (US), воронка «пошук → скринінг відгуків → прапорець «обіцяють і не дають» (≥ 1/3 скарг) → глибокий розбір», інструмент перевірки відгуків за словами-маркерами. Сирий запит Ігора в бриф навмисно не вставляли. Джерело — scratchpad сесії, тож для правок: `Artifact read` за URL → publish з `url`. Копія в репо: `docs/research/briefs/NASUF-tiktok-30-09-2026/index.html` (30.09.2026). Правиш артефакт — перезбережи й копію. Результат Nasuf доведено до звіту для менеджера 30.09.2026: див. [[tiktok-competitor-analysis]].

Потік: менеджер **Ігор** кидає сиру задачу одним-двома реченнями → VELDAN просить переписати її в бриф, зрозумілий розробнику (що аналізувати, як, який результат) → розробник робить аналіз у форматі SMS-звіту ([[sms-competitor-analysis]]).

**How to apply:** новий бриф будувати за структурою попередніх (контекст із трьома вертикалями, що шукати, що зібрати, головні питання, ризики, формат результату, метод), давати лінки на SMS-звіт і сусідні брифи. У репо — лише коли скажуть зберегти ([[artifact-then-save-on-request]]).
